# «Расписсание» — независимый проект расписания (PWA)

Тестовая версия с лёгким табличным интерфейсом, архивом недель, справочником преподавателей и отдельным конструктором. **Это неофициальный независимый проект; он не представляет администрацию учебного заведения.** В интерфейсе, метаданных и иконках нет институционального названия и эмблемы.

## Быстрая публикация на GitHub Pages

1. Создайте публичный репозиторий, например `raspissanie-test`.
2. Загрузите **содержимое** распакованного ZIP в корень репозитория, рядом должен быть `index.html`.
3. Выберите `Settings → Pages → Deploy from a branch`, ветку `main`, каталог `/(root)`.
4. Сайт откроется по `https://USERNAME.github.io/raspissanie-test/`.
5. Редактор — `https://USERNAME.github.io/raspissanie-test/editor/`.

Для тестирования установки PWA сайт должен быть доступен по HTTPS (GitHub Pages). Откройте страницу на телефоне и воспользуйтесь командой браузера «Добавить на главный экран» / «Установить приложение». Манифест и service worker используют относительные пути — проект работает в подпапке GitHub Pages.

## Структура

- `index.html` — публичный просмотр.
- `editor/index.html`, `editor/app.js`, `editor/style.css` — ручной редактор и импорт XLSX/CSV/текстового PDF.
- `assets/raspissanie-mark.svg` — нейтральный знак, `assets/icons/*` — иконки PWA.
- `manifest.webmanifest`, `sw.js`, `assets/pwa.js` — установка PWA и офлайн-кэш.
- `data/weeks/YYYY-MM-DD.json` — независимые файлы недель, `data/weeks/manifest.json` — перечень недель.
- `data/teachers.json` — справочник преподавателей, 18 записей.
- `offline.html`, `editor-offline.html` — автономные HTML для просмотра и редактирования без веб-сервера.
- `tools/build_offline.py`, `tools/build_editor_offline.py` — пересборка автономных HTML после изменения JSON.
- `branding/` — заметки о сохранённом оформлении и экспериментальном названии.

## Как обновлять расписание

Редактор сохраняет черновик **в браузере**, а не на GitHub. После проверки скачайте JSON недели и замените файл в `data/weeks/`. Для новой недели обновите и `data/weeks/manifest.json`. Исходные документы в проект не включены. Преподаватели связаны с занятиями по ID. Загружены недели 16–21 и 23–28 ноября 2026; для второй недели записаны 14 групп, а 305-я остаётся незаполненной согласно исходным материалам.

## Офлайн и безопасность

После первого успешного открытия по HTTPS service worker кэширует оболочку сайта и недели из манифеста. При наличии сети выбирается свежая версия; без сети используется сохранённая. После изменения брендинга **обязательно откройте опубликованный сайт онлайн**, чтобы обновился старый PWA-кэш. В старом локальном редакторе могут остаться черновики под прежним ключом хранилища: перед заменой сборки при необходимости экспортируйте их в JSON, затем импортируйте в новый редактор.

Для локального запуска из папки:

```bash
python3 -m http.server 8000
```

Публичные страницы размещены без авторизации: любой может открыть редактор, но изменить файлы репозитория без разрешения не сможет. Цифровые PDF обрабатываются экспериментально; OCR сканов/фото пока не реализован. Наличие расписания на публичном сайте само по себе не делает его официальным: значения следует сверять с источниками.
