# Оформление проекта

Тестовое название: **«Расписсание»**, с розовым выделением части «ссание».
Визуальная структура сайта (светлый табличный интерфейс, таблицы, поиск, архив недель) сохранена.

Ранний вариант назывался **«пара.»**. Его фирменные институциональные изображения и тексты сознательно не входят в этот публичный пакет. Для смены названия в будущем достаточно изменить тексты в `index.html` и `editor/index.html`; данные расписания от этого не зависят.

Иконки PWA и знак проекта — нейтральный календарь, созданный специально для текущей версии.
