# Справочник дисциплин

Данные: `data/subjects.json`. В нём находятся устойчивые ID, полные названия, старые сокращения (`aliases`), преподаватели, частоты занятий и номера аудиторий по каждому преподавателю. Эти сведения — **подсказки**, не жёсткие ограничения.

При добавлении недели загрузите JSON через редактор либо положите его в `data/weeks/`, затем для пересчёта справочников запустите:

```bash
python3 tools/build_subjects.py
python3 tools/build_room_patterns.py
python3 tools/build_offline.py
python3 tools/build_editor_offline.py
```

Названия курсов беспилотных авиационных и транспортных систем пока объединены **предварительно**. Оригинальные варианты сохранены как псевдонимы; при необходимости их можно снова разделить. Названия преподавателей идентифицируются по `teacherId`, дисциплин — по `subjectId`, поэтому позднее можно добавить перевод **интерфейса, подписей, названий предметов и отображаемых имён преподавателей** без изменения идентификаторов. Сейчас реализован только русский язык.

Справочник строится из данных опубликованных недель, а не из локальных черновиков посетителей. Нестандартную аудиторию программа не исправляет автоматически.
