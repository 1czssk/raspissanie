# Локализация «Расписсания»

Русский (`ru`) — основной и канонический язык данных. Публичный сайт и редактор используют `data/i18n.json` для отображения: **41 вариант языка**, **41 дисциплина**, по **основных элементов интерфейса** и по **15 расширенных текстов** на язык. Переводы не изменяют исходные JSON-файлы недель.

## Редактирование переводов

- `data/i18n.json`: `languages[]` описывает варианты и порядок в селекторе; `translations[lang].subjects[subjectId]` содержит переводы названий дисциплин; `translations[lang].ui` и `extras` — текст интерфейса.
- `data/subjects.json`: русские названия, `id` и внутренние `aliases` (старые сокращения для распознавания фотографий/импорта). Сокращения в интерфейсе не показываются. Не удаляйте алиасы, если требуется распознавать старые документы.
- `data/teachers.json`: русские имена, инициалы и постоянные `id`. Локализация делает транслитерацию, не придумывая полные имена и отчества.
- `assets/i18n.js`: механизм переключения, сохранение выбранного языка на устройстве в `localStorage`, сопоставление переводов с каноническими `id`, вспомогательная транслитерация.

Для новой дисциплины создайте уникальный `subjectId`, русское каноническое имя и переводы для нужных языков. При отсутствии перевода появляется русское каноническое название. Сохраняйте отдельную проверку новых терминов и необычных связок (преподаватель/предмет/аудитория) при импорте.

**Точность переводов:** это первые рабочие варианты, а не утверждённые отраслевые переводы. Особенно экспериментальны `tok` (токи пона: нет устоявшейся авиационной терминологии) и `ko-N` (северокорейский языковой вариант). Некоторые подробные системные сообщения могут быть на английском или русском: тексты следует вычитывать носителями языка. Авиационная безопасность (security) и безопасность полётов (safety) — разные дисциплины.

После обновления словарей обновите имя кэша в `sw.js`, пересоберите автономные HTML:

```
python3 tools/build_offline.py
python3 tools/build_editor_offline.py
```

## Дополнение: пять экспериментальных языков

- `isv` — **межславянский**, латиница, предварительная терминология; справочно: ISO 639-3 `isv`.
- `la` — **латынь**, учебная неолатинская терминология, не нормативные авиационные термины.
- `bxr` — **бурятский** (бурятская кириллица), предварительный перевод с техническими заимствованиями; `bxr` = российский бурятский.
- `ns84` — **новояз-1984**, **авторская стилизация на русском**, не словарь из романа. По заданию пользователя **Самоподготовка → сампо**. Код `ns84` внутренний, в HTML применяется частный тег `x-newspeak`.
- `tlh` — **клингонский**: игровая локализация авиационной терминологии и интерфейса с сочетаниями клингонских корней вместо английских кальк. Создана для развлечения.

В списке языков сначала русский, английский, далее варианты по русскому алфавиту. Названия дисциплин (все 41) и основные 84 элемента интерфейса перечислены для каждого варианта в `data/i18n.json`; источник расписания остаётся русским. Для новых языков 15 расширенных описаний также имеют отдельные значения. При публикации важно обновлять `sw.js`, затем пересобирать оба автономных HTML.

## Дополнение: шведский язык и краткие названия

- `sv` — **Шведский / Svenska** (`sv-SE`): переводы 41 дисциплина и основных элементов интерфейса.
- В селекторе языки с нелатинским или латинским самоназванием показываются через `/`, например «Греческий / Ελληνικά».
- Новояз: **Каб**, **Жизбез**, **Физо**, самоподготовка по-прежнему **сампо**.
