Как работает импорт

Excel: поддерживается таблица с колонками «Дата / Группа / Пара / Предмет / Преподаватель / Класс», а также экспериментальное чтение широких таблиц по группам.

PDF: извлекается текстовый слой. Скан без текста и фотография остаются источником для ручного переноса — облачное ИИ-распознавание пока не подключено.

Проверка расписания

Проверяем заполнение, пересечения, непривычные предметы и аудитории по опубликованному архиву.

Публикация пока ручная. Редактор не умеет менять публичное расписание на GitHub Pages. Для обновления нужно скачать JSON недели, заменить соответствующий data/weeks/ГГГГ-ММ-ДД.json в репозитории и, если неделя новая, добавить её в manifest.json. Список недель можно скачать кнопкой «Скачать manifest»..
